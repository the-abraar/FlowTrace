# BlankFrame FlowTrace Pitch Deck Content

**Slide 1: Title**
*   **Headline:** BlankFrame FlowTrace: The Invisible Intelligence Layer
*   **Sub-headline:** Understand your physical spaces like you understand your website.

**Slide 2: The Problem**
*   **The Status Quo:** Physical venues (like Togi Fun World) fly blind. They count tickets sold, but not *how* people spend their time.
*   **The Pain Point:** You don't know where bottlenecks form, which games cause hesitation, or the true dwell time per zone.

**Slide 3: The Solution - Passive Tracking**
*   **Our Approach:** "The user just walks; the system does the thinking."
*   **No Friction:** No apps to download, no QR codes to scan. We use hidden ESP32 nodes and passive BLE wristbands (or existing smartphone BLE signals).

**Slide 4: How It Works (The 3 Pillars)**
1.  **Sense:** Invisible BLE nodes triangulate position via signal strength (RSSI).
2.  **Analyze:** Real-time backend maps movement into actionable "Shadow Profiles".
3.  **Act:** LangChain AI agent triggers notifications (e.g., "Long queue at VR, send 10% discount for Laser Tag to waiting users").

**Slide 5: The "Agentic" Difference**
*   *Most analytics just show a dashboard.* FlowTrace thinks.
*   Instead of "Zone A has 50 people," FlowTrace says: "30% of users stayed near the new VR game but didn't play. Recommendation: Add a second machine."
